# EraTrans

EraTrans 是一款用于 ERA 游戏的 Windows 翻译工具，支持文本提取、字典编辑、AI 辅助翻译，并将译文应用到独立的游戏副本中。

## 主要功能

- **提取字典**：扫描游戏文件，按原目录结构生成 JSON 字典，并保留原有 key 和其他字段。
- **编辑译文**：支持搜索、查看词条上下文、修改翻译状态，以及编辑长文本和多行译文。
- **AI 翻译**：支持 OpenAI 兼容接口，可翻译选中词条或未翻译词条；ERB 语义分组翻译可按需启用。
- **安全应用**：完整复制游戏到输出目录后再应用译文，原游戏目录不会被修改。
- **解析设置**：可配置文件编码、变量过滤、重复词条合并等解析规则。

## 输出目录

选择原游戏目录和统一输出目录后，程序会按游戏目录名称分类保存：

```text
输出目录/
└─ 游戏名称/
   ├─ 字典/
   ├─ AI上下文/
   └─ 游戏副本/
```

## 下载与运行

从 GitHub Actions 的成功构建中下载 `EraTrans-win-x64`，解压后运行 `EraTrans.App.exe`。程序已包含 .NET 运行时，无需单独安装。

配置文件保存在程序旁的 `Config/` 文件夹中。请将程序放在当前用户有写入权限的目录下运行。
