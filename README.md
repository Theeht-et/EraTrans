# EraTrans

EraTrans 是一款面向 ERA 游戏的 Windows 桌面翻译工具，用于提取游戏文本、编辑和翻译字典，并将译文应用到游戏副本。

## 主要功能

- **提取字典**：扫描游戏目录，提取可翻译文本并生成 JSON 字典。
- **编辑管理**：按文件夹浏览字典，搜索词条，查看原文和上下文，编辑译文及翻译状态；支持长文本编辑。
- **AI 翻译**：接入 OpenAI 兼容接口，可翻译选中词条或未翻译词条；ERB 文件可选用语义分组上下文。
- **解析设置**：可配置文件编码、变量过滤、文件扩展名等解析规则。
- **应用译文**：完整复制游戏目录，再将译文应用到副本。原游戏目录保持不变。

## AI 服务商设置

在“编辑字典”中打开“AI 服务设置”：

- 左侧列表可启用/禁用服务商，并通过上移、下移调整顺序。
- 内置服务商不可删除或改名，可恢复默认 API 地址；自定义服务商可以新增、命名和删除。
- 每个配置需要 OpenAI 兼容的 Base URL、API Key 和模型 ID。可以尝试“获取模型”后选择，也可以手动填写模型 ID。
- 选择“设为翻译服务”后保存，才会作为当前翻译服务。禁用或配置不完整的服务商不会被用于翻译。
- 当前统一使用 OpenAI Chat Completions 协议；模型列表通过可选的 OpenAI 兼容 `GET /models` 接口获取。不支持模型列表接口的服务商仍可手动配置模型。
- API Key 使用当前 Windows 用户的 DPAPI 加密，保存在程序目录旁的 `Config/ai-providers.json`。配置文件不能直接移植到其他 Windows 用户并期待原密钥自动解密。

AI 请求记录保存在 `Config/ai-translation-logs`，包含请求提示词和模型响应，不保存 API Key。记录可在“AI 请求记录”窗口中查看和清理。

## 基本使用

1. 选择原游戏目录和统一输出目录。
2. 点击“开始提取字典”。
3. 在“编辑字典”中手动编辑或使用 AI 翻译，检查后保存。
4. 点击“完整复制游戏并应用译文”，生成翻译后的游戏副本。

输出目录按游戏名称分类：

```text
统一输出目录/
└─ 游戏名称/
   ├─ 字典/
   ├─ AI上下文/
   └─ 游戏副本/
```

## 下载

在 GitHub 仓库的 **Actions** 页面打开成功的 CI 运行，在 Artifacts 中下载 `EraTrans-win-x64`，解压后运行 `EraTrans.App.exe`。程序已包含运行环境，无需单独安装 .NET。

## 技术
