# EraTrans

EraTrans 是一个把 ERA 游戏文本翻译成中文的 Windows 小工具：从游戏目录里提取文本，帮你逐条翻译，再把译文写进一份游戏副本。**原来的游戏文件不会被改动。**

## 能做什么

- **提取文本**：选择游戏目录，自动把需要翻译的文本整理成字典文件。
- **编辑翻译**：按文件夹浏览字典，搜索词条，查看原文和上下文，逐条填写译文。
- **AI 翻译**：接入常见的大模型服务，可以只翻译选中词条，也可以一次翻译所有未翻译词条。
- **应用译文**：复制一份游戏目录，把译文写进副本。

## 使用流程

1. 选择原游戏目录和输出目录。
2. 点击「开始提取字典」。
3. 在「编辑字典」里手动修改，或使用 AI 翻译。
4. 点击「完整复制游戏并应用译文」。

输出目录会按游戏名分类：

```text
输出目录/
└─ 游戏名称/
   ├─ 字典/
   ├─ AI上下文/
   └─ 游戏副本/
```

## AI 服务

- 已内置 OpenAI、DeepSeek、通义千问、智谱、Kimi、火山方舟、硅基流动、OpenRouter、Grok，也可以添加任何兼容 OpenAI 接口的自定义服务。
- 每个服务只需要填写 API 地址、API Key 和模型名；支持「获取模型」下拉选择，也可以手动输入。点「测试连接」可以确认能不能用。
- **推理开关**：在字典编辑界面右上角，可以为当前使用的模型选择「自动 / 开启 / 关闭」。
  - **自动**（默认）：不额外设置，沿用服务商自己的默认行为。
  - **开启 / 关闭**：用于较复杂的文本，或服务商默认开着推理而你想关掉时。
  - 如果某个模型不接受这个设置，程序会自动去掉它重试一次，翻译不会因此失败。
- 想用其他字段时，可以在「AI 服务设置 → 推理字段（可选）」里自己填写，留空即使用默认值。

API Key 只保存在你自己的电脑上（使用 Windows 自带的加密方式），不会上传到任何服务器。每次 AI 请求的内容都记录在程序目录的 `Config/ai-translation-logs` 里，方便排查。

## 下载

打开仓库的 **Actions** 页面，进入最近一次成功的运行，下载 `EraTrans-win-x64`，解压后运行 `EraTrans.App.exe`。程序自带运行环境，不需要另外安装 .NET。
